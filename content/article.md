# 歡迎來到這裡

這是一個由 Markdown 產生的靜態文章頁面。將本檔案的內容換成你的文章，然後執行 `npm run build`。

## 為 Telegram Instant View 而設計

文章會在建置時轉為 HTML，而不是交給瀏覽器用 JavaScript 轉換。因此 Telegram 可以直接讀取穩定的文章結構。

- 以 Markdown 寫作
- 以 GitHub Pages 發佈
- 以 Telegram Instant View 閱讀

> 這個頁面刻意保持簡潔，讓內容成為焦點。

[Telegram Instant View 文件](https://instantview.telegram.org/docs)
